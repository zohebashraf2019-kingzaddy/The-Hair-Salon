# The Hair Studio Reno

Static HTML/CSS/JavaScript website prepared for GitHub + Vercel.

## Files
- `index.html` — website
- `styles.css` — responsive design
- `script.js` — mobile menu, gallery lightbox and next/previous arrows
- `assets/` — supplied logo, owner image and portfolio photos

## Deploy to GitHub
1. Create a new repository.
2. Upload all files and the `assets` folder.
3. Commit the files.

## Deploy to Vercel
1. In Vercel, choose **Add New > Project**.
2. Import the GitHub repository.
3. Framework preset: **Other**.
4. Build command: leave blank.
5. Output directory: leave blank.
6. Deploy.
